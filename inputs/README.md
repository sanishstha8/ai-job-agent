# Put your documents here

| File | What it is |
|---|---|
| `cv.pdf` (or `cv.docx`) | Your CV / resume. This exact file is uploaded to applications, so use PDF or DOCX. |
| `cover_letter.docx` (or `.pdf` / `.txt`) | One of your existing cover letters. The agent copies its tone and style; it never sends this file as-is. |
| `target_job.md` | A plain-text description of the job you want. Copy `target_job.example.md` to `target_job.md` and edit it. |

The files in this folder stay on your computer. Their text is sent to the Claude API when jobs are scored and cover letters are written.
